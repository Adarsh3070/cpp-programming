# C++  Programming

A collection of C++ programs demonstrating object-oriented programming concepts.

## Projects

### 1. Rectangle Geometry
- Calculates the area of a rectangle.
- Calculates the perimeter of a rectangle.
- Compares two rectangles based on their areas.

### 2. E-commerce Discount System
- Accepts product details.
- Displays the original price and discount percentage.
- Calculates the final price after applying a discount.

### 3. Distance Addition
- Works with distances represented in different units.
- Demonstrates addition between objects of different classes using friend functions.

### 4. Bank Transaction System
- Initializes bank account details.
- Supports deposits and withdrawals.
- Checks the current account balance.

### 5. ATM Management System
- Implements an ATM system using a C++ ATM class.

- Uses static data members to track the total cash available in the ATM and the total number of card transactions.

- Implements CashWithdraw() to withdraw cash from    the ATM.

- Implements CashDisplay() to display the available cash and transaction count.

- Uses a static member function ATMCash() to  display the total cash available in the ATM.

- Demonstrates the use of an array of objects.

### 6. Password Strength Checker(Basic)
- Accepts a password from the user.
- Counts uppercase letters, lowercase letters, digits, and special characters.
- Uses a `for` loop to analyze the password.
- Classifies password strength as Weak, Moderate, or Strong based on the specified rules.

### 7. Shopping Bill and Discount System(Basic)
- Accepts multiple item prices from the user.
- Calculates the total bill.
- Uses `break` and `continue` statements.
- Ignores negative prices and displays a warning.
- Applies a 10% discount when the total bill exceeds ₹5,000.

### 8. Traffic Signal System(Basic)
- Accepts a traffic light color as input.
- Uses `if-else` statements to determine the appropriate action.
- Displays:
  - Red → Stop
  - Yellow → Get Ready
  - Green → Go
- Handles invalid inputs.


## Concepts Covered

- Static data members
- Static member functions
- C++ Classes and Objects
- Friend Functions
- Encapsulation
- Private Data Members
- Object-Oriented Programming

## Language

- C++

## Compilation

Compile a program using a C++ compiler such as g++:

    g++ rectangle_geometry.cpp -o rectangle_geometry

Run the compiled program on Windows:

    rectangle_geometry.exe
