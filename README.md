# C++ Friend Function Programs

A collection of C++ programs demonstrating object-oriented programming concepts, with a focus on friend functions.

## Projects

### 1. Rectangle Geometry
- Calculates the area of a rectangle.
- Calculates the perimeter of a rectangle.
- Compares two rectangles based on their areas.

### 2. E-commerce Discount System
- Accepts product details.
- Displays the original price and discount percentage.
- Calculates the final price after applying a discount.

### 3. Distance Addition
- Works with distances represented in different units.
- Demonstrates addition between objects of different classes using friend functions.

### 4. Bank Transaction System
- Initializes bank account details.
- Supports deposits and withdrawals.
- Checks the current account balance.

## Concepts Covered

- C++ Classes and Objects
- Friend Functions
- Encapsulation
- Private Data Members
- Object-Oriented Programming

## Language

- C++

## Compilation

Compile a program using a C++ compiler such as g++:

    g++ rectangle_geometry.cpp -o rectangle_geometry

Run the compiled program on Windows:

    rectangle_geometry.exe
